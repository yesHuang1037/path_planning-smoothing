## 2. 第一阶段必须实现 / 暂不实现

### 必须实现

1. 接收现有静态图、TF 位姿、目标和动态 costmap，建立一致的二维地图/坐标查询；静态图是全局底图，不另建 SLAM、点云感知或 map_server。
2. 普通二维 8 邻域 A*，使用统一占据/净空判据；得到明确的初始折线路径和成功/失败原因，而非“失败返回起点也算路径”。
3. TDT 风格的碰撞感知 DP 化简和可见弦合并；任何替代连线必须满足同一通行规则，不仅比较几何偏差。
4. 分段多项式、固定段时长下的 QP 优化，第一阶段**建议固定 minimum-jerk + 五次多项式 + OSQP 走廊后端**；包含段间连续性、端点及速度边界、走廊约束。
5. 对优化结果采样/细分、检测，发现碰撞后插点或收紧自动走廊并重解；迭代、控制点数、采样量和时间均有预算；耗尽仍碰撞则失败。
6. 生成最终几何 Path，检查整个最终结果及精确起终点连接，再通过现有 MPC 接口交付。不得发布后再补查。
7. 实现 global_monitor 同等重规划触发边界：新目标、周期、停滞；碰撞可被监控但不直接触发搜索，关闭路径截断。第 10 节确认动态层是否参与全局求解。
8. 明确失败、无参考、过期输入和规划版本变化的处理；第一阶段基线建议失败即撤销旧参考，不实现复杂的旧轨迹限时保留策略。执行安全门闸见第 6 节，需确认修改权限。
9. 提供独立启动入口、分阶段调试输出、失败原因、耗时统计和离线测试；随后通过现有实机链路验收，不以搭建仿真为前置条件。

### 未来扩展

- minimum-snap（四阶目标、八个系数/七次多项式）、多目标混合权重和后端自动切换；不在首期同时维护多套默认算法。
- Kinodynamic A*、JPS 混合、动态障碍运动预测、时空搜索、多拓扑候选。
- 定时/速度/加速度轨迹消息及 MPC 时间跟踪改造、规划与执行联合时间优化。
- 车体任意多边形随姿态扫掠、完整曲率/非完整约束；首期只在实际底盘允许二维平移的前提下采用保守圆形包络。
- 起点穿障脱困、自动替换被占据目标、楼梯/地形语义、旋转地图支持。
- 全新距离场、SLAM、感知、底盘或 MPC 模型重写、15～20 ms 硬实时保证。

上述“未来扩展”不是说实机可忽略其对应风险：例如实际底盘不允许任意二维平移，就不能将此二维基线直接部署，只能先离线验证或重新限定当前规格。

## 3. 输入与坐标约定

除格索引外，内部规划统一在 map 中使用米和秒。二维索引明确定义 row/col，消息索引按 row×width+col；世界坐标转格使用 floor，不能向零截断。初始支持地图 origin yaw=0，非零旋转显式拒绝而非静默误解。

| 输入 | 接口/单位 | 最小语义 |
| --- | --- | --- |
| 静态图 | `/map`，nav_msgs/OccupancyGrid；resolution=m/格，origin=m、四元数 | 读取 metadata 和精确 data 长度；0 空闲、1～100 首期保守视为占据、-1 未知视为占据，非法值拒绝。不把像素尺寸写死为 0.05 |
| 机器人位姿 | TF map←base_link；x/y=m，yaw=rad | 优先正常 TF 链；有时间有效性检查，不靠忽略外参拼凑坐标。地图配准由现有定位链负责，规划仅能验证约定，不能证明配准正确 |
| 起点速度 | 首选连续有效 TF 的位移差分得到 map 中 vx/vy，m/s | 与当前 MPC 的 TF 状态来源相容；静止时可显式零速度，运动中不得无条件填零。TF 无法提供稳定估计则保持/失败，不用上一条命令冒充测量 |
| 目标 | `/goal_pose`，geometry_msgs/PoseStamped；x/y=m | 变换到 map，拒绝非法坐标/frame；目标序号在接收端递增。首期约束位置，不承诺终端 yaw，原目标与实际使用目标不得混淆 |
| 动态全量 | `/costmap/costmap`，nav_msgs/OccupancyGrid | 依消息 resolution/origin/frame 转换；0～100 标准占据语义，占据阈值初值 65；不凭 int8 数值猜测 0～254 原始编码。如实际编码不同，明确适配 |
| 动态增量 | `/costmap/costmap_updates`，map_msgs/OccupancyGridUpdate | x/y 是格偏移，width/height 是格数；必须有已接收全量作为底图，长度必须等于矩形面积。按发布者实际 QoS 匹配，不照搬旧订阅参数 |
| 执行速度及模式 | 继续由现有 MPC 的 `/setFollowSpeed`、should_rotate 等接口处理 | 不把它们改成 QP 时间分配接口；本规格不修改其单位/协议 |

静态图首期加载后固定；收到内容/metadata 改变的静态图，应使已有规划失效并进入显式重载/重新规划流程，不在求解中悄悄混用。未知区域、地图边界与动态窗口外的规则必须分开：局部窗口外表示没有当前动态覆盖，不自动抹掉静态障碍，也不能宣称已经检查动态安全。

动态层建议保留原生全量快照，应用增量后生成保守映射的占据集合。0.10 m 粗格按其完整足迹覆盖所有相交的 0.05 m 细格；不能只映射中心。全量重建替换该源集合、增量清除不影响静态层。原点移动时必须随全量重新同步，无法判明增量归属时停止使用不可靠增量、等待重同步；仅靠消息头时间不保证跨话题一致性。

## 4. 算法流水线与成功定义

```text
静态底图 + 当前动态层（建议） → 统一占据/净空快照
TF 起点/速度 + 新目标 → A* 初始折线
  → 碰撞感知 DP → 可见弦合并
  → 矩形走廊 + 段时间分配
  → minimum-jerk QP
  → 曲线细分检测 → 插点/收紧走廊 → 重解（有预算）
  → 最终检查 → 按弧长重采样 → 再检查实际发布折线 → /sPath → 原 MPC
```

### 4.1 地图与搜索

- 复用原 ESDF/DynamicVoronoi 的基本距离/最近障碍查询，但通过一个使用米的环境接口统一几何与占据。不得并存不同原点、0.05 硬编码和不同障碍真假语义。
- 原模块已知共享地图双重释放风险必须在新副本接入时解决，不能用 no-op deleter 当成退出/生命周期修复；不要求换另一套距离场。
- 首期建议使用以 base_link 为参考的保守车体外包圆半径，加安全/离散化余量，形成统一通行判据；不能把内接半径 0.01 或 MPC 的 ObstacleInflation 直接当成实车外形。
- 静态图预膨胀、动态层膨胀与本层车体补偿分开记录，语义未知时不得宣称已补偿。距离场是格中心距离，不应不经补偿地当成连续障碍边界精确距离。
- A* 普通 8 邻域，首期建议欧氏启发权重 1，加非负距离惩罚；代价统一在米/无量纲归一化的定义中，障碍权重不得悄悄随分辨率改变。对角移动不穿越障碍角，所有边遵守同一连线检查。
- 起终点越界/占据/净空不足时明确失败；暂不继承旧穿障脱困或自动替换目标。精确起终点与格代表点之间的接入线同样检查；近目标返回独立到达状态，不伪造单点成功路线。

### 4.2 QP 与迭代

建议首期固定目标：J=Σ∫(x'''(t)²+y'''(t)²)dt。每段五次多项式，段时长固定为正值；起终点位置固定、起点速度取有效状态、终点速度为零、内部位置/速度/加速度连续（C2）。起点加速度没有可靠输入时不冒充测量硬约束。

- 可借用 TDT 的分段梯形时间分配思路，但去重后验证所有时长有限且大于下限；v_alloc、a_alloc 只决定优化时间尺度，不是 MPC 实际执行限值。
- 矩形走廊由统一安全环境生成，限制中间连接点位置；不强行要求穿过全部 A* 点。端点固定，边界速度不可因走廊收缩而丢失。
- **走廊约束作用于连接点，不代表整段多项式都在走廊内**。必须检查曲线，不能以 QP 可行替代避障认证。
- 采样不能只照搬每段 11 点。首期使用有界曲线细分：限制弦长和曲线到弦的偏差，逐格保守检查弦线段，并把已知曲线偏差计入余量；达到细分预算仍无法验证则失败。可使用二阶导数区间上界获得偏差界，不要求首期引入复杂的全局多项式证明框架。
- 针对碰撞分段交替恢复参考折线上的控制点/插点、收紧相关自动走廊并重解；插入点必须来自已验证参考，不能把两个优化点的中点默认当安全点。
- 统一检查求解器状态、有限系数、约束残差、端点与连续性。仅取到解向量、非空路径或达到最大迭代均不算成功；误差超限、不可行、超时按失败处理。不自动退回闭式求解、旧样条或未认证 A* 折线并发布成功。
- 求解全过程使用一致的地图快照。发布前核对目标版本、最新环境和机器人起点漂移；过期结果丢弃或重新验证，不能覆盖较新的目标/参考。一次最多一个求解任务，合并重复请求，不堆积旧周期搜索。

### 4.3 输出

| 输出 | 接口/单位 | 语义 |
| --- | --- | --- |
| 执行参考 | `/sPath`，nav_msgs/Path；map，位置 m，姿态四元数 | 仅发布最终有效路径；按近似等弧长采样以适配现有按索引取点 MPC。保留精确端点、去除重复点；不得以每点时间戳声称 MPC 按时间执行 |
| 可达标志 | `/ly/navi/reachable`，std_msgs/Bool | true 仅表示最终参考通过检查且可交付，不是 A* 刚成功；不作为独立的停车保证 |
| 规划状态与证据 | 建议 `/tdt_planner/status`，diagnostic_msgs/DiagnosticArray | 原因、目标/地图版本、结果有效性、各阶段耗时、QP 状态、迭代数、最小净空；是观测接口，不要求新建定制消息协议 |

Path 姿态可由切线生成用于显示/兼容，但不能据此承诺实车沿切线转头；当前 MPC 模型与终端 yaw 控制不是本阶段新增功能。原 MPC 的索引取模在末端可能回绕，实机前须通过终点跟踪验证；若需修正，应限于新工作区执行副本，不能靠重复堆叠末点掩盖。

## 5. 重规划：沿用 global_monitor 的触发边界

| 事件 | 第一阶段行为 |
| --- | --- |
| 首次/新目标 | 输入有效则从当前状态完整规划；不受普通 1.5 s 节流限制，旧目标在途结果不得生效 |
| 静态图首次就绪 | 如已有待处理目标则执行首次规划，不因启动先后丢掉目标 |
| 动态全量/增量 | 更新环境、检查当前参考；不以 CostmapBlocked 等原因立即搜索 |
| 监控定时器 | 建议沿用 0.50 s；在有目标、状态有效、未到达条件下检查参考、停滞并申请周期搜索 |
| 周期请求 | 建议沿用最小请求间隔 1.5 s；共享最后放行时间，搜索失败也消耗间隔，不是硬实时周期或单次耗时预算 |
| 停滞请求 | 初值沿用 12 s 窗口、位移≤0.03 m、离目标≥0.30 m，受同一间隔限制；时间回退/位姿跳变重置锚点 |
| 碰撞原因 | 记录但不直接触发搜索；不做路径截断/临时禁行记忆。不得将它解释为允许继续执行已知无效参考 |

手动重规划只保留内部原因与未来入口，不为第一阶段额外发明必须接入的服务。预算计时使用单调时钟；输入时间用 ROS 时间及明确的失效规则，不把 wall timer 与 ROS 时间混用后的行为称为硬实时。

**重要待决点**：第 6 节建议的安全暂停独立于重规划原因过滤。监控发现旧参考失效后可先保持，仍只等允许的周期/新目标搜索恢复。这比原 global_monitor 单纯报警多了一层执行保护，必须明确确认，不能暗中宣称完全复制旧行为。

## 6. 失败与执行交付的最小协议（建议，待确认）

- 状态至少区分等待输入、求解中、有效参考、无效/保持、到达。QP 成功不能直接置整链成功；失败不能伪装成“到达当前位置”。
- 初次无参考、规划失败、TF/必需感知过期、当前参考已知失效时，撤销参考并保持；安全暂停不等待 1.5 s 搜索节流。新有效参考与输入恢复后才能解除。
- 当前 MPC 的空 Path 已会清参考并发零控制，建议以此作为兼容起点，不发布机器人当前位置单点。空 Path 不改变原任务目标，也不触发 reached=true。
- 一次空消息不能覆盖规划器崩溃/断联风险。实机放行需要 MPC 或最终命令链一侧的参考/许可超时保护；若增加有效性心跳，必须关联当前参考版本且只在输入和参考仍有效时续期，不能靠重复发布旧路径续命。
- `/Path_downsampled` 首期不是 MPC 前置接口，不默认启动无明确消费者的 path_publisher；若必须保留，需在副本中补齐空参考清除语义并验证消费者，不允许继续重发旧缓存。
- 不重写 MPC 算法；允许的候选兼容修改仅限参考撤销/超时/必要末端边界，授权及工作区范围见第 10 节。若不允许这些保障且末端无等效机制，阶段只能验收到候选路径/非驱动联调，不能标记实机运动闭环已验收。

## 8. 关键正确性边界与验收

| 边界 | 第一阶段判据 |
| --- | --- |
| 地图未就绪、空数据、分辨率≤0、长度不符、旋转原点 | 明确等待/拒绝，不能越界、用默认原点或继续发成功 |
| 负坐标、格边/角、对角切角、地图外 | 转换一致，连线覆盖所有触及的障碍格；车体包络不可越过地图边界 |
| 粗细格不对齐、原点移动、多粗格覆盖同一细格 | 保守保留面积；清除不误删仍被其他粗格占据的细格，也不清静态层 |
| 动态增量先于全量、QoS 不通、断流、重启 | 不伪造已更新；可观测等待/过期与重同步；实机许可按确认规则失效 |
| 起终点非法、重复/极短路径、起点在障碍、目标被占据 | 返回结构化失败/到达，不靠穿障或偷偷换目标让测试通过 |
| 窄通道、S 弯、走廊交集为空、QP 不可行 | 成功须经统一检测；预算耗尽返回失败，不发布仍碰撞的最后一轮候选 |
| 曲线与折线不一致 | 曲线细分误差受界，最终弧长重采样产生的新连接边再检查；不只认证中间结果 |
| 新目标抢占、地图更新、求解时车体移动、时间跳变 | 过期结果不能替换新参考；监控/停止不被长求解阻塞；停滞与节流状态有明确重置规则 |
| MPC 几何跟踪与 QP 时间不同 | 验收分开记录几何安全、优化导数和实测速度/加速度，不宣称 minimum-jerk 保证整车 jerk |
| 失败/断联/到达与末端跟踪 | 空参考不误报到达，命令链保持/超时可验证；参考末端不因索引回绕产生错误运动 |

验收分四个连续切片，不把离线通过冒充实机通过：

1. **P1-A 输入/地图/普通 A***：静态、动态映射与坐标测试，原链只读采集；初始路线及失败语义可复现。
2. **P1-B 化简/QP/检测迭代**：直线、单拐角、S 弯、窄通道、无解和预算耗尽等离线场景；端点/连续性/残差/最终折线检查通过。必须走实际 QP 后端，不以旧样条替代。
3. **P1-C ROS 与 global_monitor**：使用现有消息和 TF，验证新目标、周期节流、停滞、碰撞原因不直接搜索，以及失效/恢复；先不驱动底盘。
4. **P1-D MPC 实机闭环**：明确实际包/参数解析、TF/地图配准、车体与速度条件、停止协议后，受控低速验证移动、替换参考、到达、阻塞/失败保持。保存话题、参数及耗时记录；不要求先建仿真。

性能记录至少分开地图更新、搜索、化简、QP 各轮、检测、输出及端到端总耗时，统计样本条件、成功率与高分位/最大观测值。15～20 ms 保留为待评估愿望，不是本阶段无数据支撑的验收承诺。
