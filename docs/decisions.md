## 本轮核实的事实：DynamicVoronoi 的职责，不是新的替换决定

- `DynamicVoronoi` 维护距离、最近障碍物索引和 Voronoi 标记；`esdf_map.cpp` 在初始化及障碍物变化后更新它。这里的 Dynamic 指地图变化后的更新，不代表运动预测。
- **A* 也使用距离场**：`src/Astar.cpp` 的邻居扩展读取 `getDist()`，参与最小净空过滤及 `getDistCost()` 障碍代价；不是只有平滑器和安全检查器使用它。起点脱困条件存在既有豁免，不能把净空检查描述为无条件保证。
- 平滑器通过 `getNearestObstacleIndex()` 调整路径点；安全检查器将距离乘地图分辨率转成米，并结合动态 costmap 净空取较小值。
- 当前规划调用链未发现沿 Voronoi 骨架搜索的接线；`isVoronoi()` 的外部调用位于 ESDF 调试着色。调试图片写出已注释，不等于完全没有可视化计算开销。
- `esdf` 的名字不证明存在完整有符号距离场：当前 `getDist()` 返回底层非负障碍距离，安全检查器按栅格距离换算，不能当作连续障碍边界的精确净空保证。

源码依据均位于 `transplant_ws/src/path_searching/`：`include/dynamicvoronoi.h`、`src/dynamicvoronoi.cpp`、`src/esdf_map.cpp`、`src/Astar.cpp`、`src/smoother.cpp`、`src/path_safety_checker.cpp`。本轮仅静态核对，未新增 DynamicVoronoi 专项运行测试，未决定删除、替换或重构该模块。
