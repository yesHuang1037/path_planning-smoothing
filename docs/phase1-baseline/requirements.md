## 2. 输入与环境契约

| 输入 | 类型与单位 | 规则 |
| --- | --- | --- |
| /map | nav_msgs/OccupancyGrid；m/格、origin m | 首期0空闲，1～100及-1保守视为障碍；尺寸/长度/编码校验，变化触发失效而非混用 |
| /costmap/costmap | nav_msgs/OccupancyGrid | 沿用现有话题，入口阈值化为内部二值掩码；标准0～100编码初值阈值65，-1未知不得当作已观察自由 |
| /costmap/costmap_updates | map_msgs/OccupancyGridUpdate | 如上游实际使用则接收，依最新完整图应用矩形更新；无全量或长度/边界不符则拒绝并等待同步 |
| TF map←base_link | 位置m、角度rad | 车体中心参考；最新动态变换须有效，静态TF时间戳不按动态数据年龄误判；map配准需实测 |
| /goal_pose | geometry_msgs/PoseStamped | 变换到map，显式目标编号；位置目标，不承诺末端yaw |

首次地图到达前可保留一个待处理显式目标，输入就绪后处理；不设定周期失败重试。每次新请求先停车，停稳后再锁定起点与地图，避免快照起点来自运动前。

坐标转换使用floor，索引统一row/col；分辨率和原点由消息读取。当前静态0.05 m/格、局部0.10 m/格仅为代码配置事实。首期仅支持轴对齐地图，非零origin旋转或不支持的frame明确拒绝，不静默忽略。

粗格按完整面积保守覆盖所有相交细格，不只投中心；全量替换该动态源，增量先维护原生快照再重建集合，避免重叠覆盖误清除。静态层不被动态清除。滚动origin改变必须用对应全量同步，无法验证更新基底时保持/等待，不靠猜测继续使用。QoS需按实际发布者核对。

局部窗口外只表示无当前动态覆盖，仍使用静态图规划；未知局部格保守阻塞，窗口外不等于整张全局地图都未知阻塞。执行许可至少要求机器人包络及当前停车/前视区域处于有效感知覆盖内，缺失则停止。区域内未知/无覆盖不能按无障碍续期。

## 3. 车体包络与净空：统一硬判据

**用户已确认**：当前四舵轮，未来四全向轮；首期外形边长0.60 m正方形，base_link默认在中心，安全余量0.08 m。

首期采用保守外接圆：

```text
R_body = hypot(0.60/2, 0.60/2) = 0.424264... m
D_required = R_body + 0.08 = 0.504264... m
通行：保守的中心到占据格面积距离下界 > D_required
```

显示可写约0.505 m，内部使用计算值，不向下取0.50 m。外接圆比方形姿态检查更保守，会拒绝部分实际可过通道，这是首期简化的代价。

保守距离必须不大于查询点到任一占据格闭合面积的真实最近距离；可复用原距离场并通过经过验证的量化/格面积补偿得到下界，不要求重建距离场。不得直接将getDist×resolution当成该面积距离。输出低于零取零；地图外视为不可通行，并检查车体包络不跨边界。

A*、化简连线、走廊及最终检测共用该米制判据。保守面积查询已处理栅格误差，不再重复添加同一份格中心补偿。曲线到弦的偏差以及离散检查点之间的距离变化须另作保守处理；可利用距离的1-Lipschitz性质或直接检查带包络的线段，不能只查少量中心点。

上游预膨胀范围需记录；未确认前不假定其已覆盖车体。禁止把MPC软代价ObstacleInflation=0.2直接抵扣本阈值。0.08 m不是制动距离保证，实际感知/停止延迟与制动距离另测；实物突出部件若超出该包络必须修订后才能放行。

## 4. 算法与交付成功定义

- 普通8邻域A*，建议启发权重1，步长米制、非负距离惩罚；上限和状态清晰。起终点非法/占据/净空不足明确失败，不自动穿障脱困或改目标。
- DP阈值是几何偏差，不是碰撞容忍。每条新弦、原始边和精确起终点接入线都检查，不把原路径当作天然已安全。
- QP目标为Σ∫(x'''²+y'''²)dt，每段6系数、五次；固定起终位置，终点速度零，停稳有效后起点速度零，段间C2连续。没有可靠起点加速度不硬填测量值。
- 时间分配参数只影响内部时间尺度，不保证MPC按该速度/加速度执行。去重，拒绝非法时长；位置走廊约束不证明整段曲线安全。
- 有界曲线细分后保守检查各段；发现碰撞，恢复安全参考折线控制点或收紧自动走廊再QP。控制点、轮数、采样、单次QP和总耗时均有预算；超限不放宽判据。
- 求解器状态、有限系数、端点、C2连续和约束残差均检查；非空输出不等于成功，不退回未认证折线/旧样条并发成功。
- 发布前检查最新环境及起点漂移。快照编号不同不一律取消：对候选路径做最新数据验证，相关占据变化不安全或验证预算不足则失败，不因10 Hz更新无限追逐快照。新目标一律使旧目标结果作废。
- 按弧长重采样适配按索引取点的MPC，精确端点保留；发布折线形成的新边再检查。地图快照安全不等于未来环境安全，执行期间另有停止监控。

| 输出 | 语义 |
| --- | --- |
| /sPath，nav_msgs/Path | 执行许可开启且最终验证通过才发布非空参考，map、m；不是定时轨迹 |
| /ly/navi/reachable，Bool | 最终可交付状态，不是A*成功即true，也不独自承担停车 |
| 调试Path/Marker/状态 | 独立命名空间，记录各阶段、快照/目标/参考编号、失败原因、QP状态、耗时和净空 |
| 空Path | 撤销参考，不伪装到达；实际停止还依赖执行端保持及超时保护 |

沿用MPC→cmd_vel→vel_forwarder→底盘；规划器不绕过MPC直接控制速度。不默认启动无明确执行需求的path_publisher；若启动，必须在副本验证空参考清缓存，不保留旧输出。

## 5. 执行边界表：先停、一次规划、显式恢复

| 情况 | 执行行为 | 规划/恢复 |
| --- | --- | --- |
| 无目标、无有效参考 | 持续保持停止 | 不搜索 |
| 有目标但输入未就绪 | 停止等待 | 输入就绪后处理该待执行请求 |
| 首次/新显式目标 | 撤销旧参考，请求停止并确认停稳 | 从最新状态快照求解；旧目标结果丢弃 |
| 正常跟踪，感知更新且前视安全 | 继续；只为当前有效参考续期 | 不自动启动搜索 |
| 前视不安全、跟踪偏离许可走廊或覆盖不足 | 立即请求停止，锁存保持 | 不自动绕行；重新显式请求并验证后恢复 |
| 地图/TF/感知过期，通信异常 | 停止保持 | 数据恢复不自动恢复旧路径；需新显式请求 |
| A*/QP/检测失败、超时 | 保持停止，reachable=false | 不自动重试 |
| 求解中显式目标改变 | 保持停止、作废旧结果 | 仅处理最新显式请求 |
| 求解中输入变更使结果失效 | 保持停止、拒绝交付 | 可在同一请求的有限预算内更新验证；否则失败待显式重试 |
| 规划器/许可发布端断联 | 执行端本地超时保持 | 不依赖上游再发空消息 |
| MPC或速度流断联 | 下游命令超时必须停止 | 无已验证等效机制不得实机放行 |
| 到达目标 | 停止，报告到达 | 该目标不自动再搜 |
| 停止请求后未停稳 | 持续停止命令并报告故障/超时 | 不以“命令为零”冒充实际零速度，不开始执行新结果 |

停止保护不等于急停认证；实车验证需人员、实体急停和隔离场地。安全监控/执行超时不得被QP阻塞，保护延迟和停车距离必须覆盖在前视安全范围中。0.50 s旧监控周期不能不测量就作为安全节拍。

最小协议优先沿用空Path清除参考；增加执行侧独立超时/许可，不能只依靠一次空消息。实现前验证新参考激活与许可关联的具体办法：许可必须绑定参考编号、节点会话和失效顺序，旧许可不能解锁新/已撤销参考；尽量复用标准消息，不引入无必要的通用消息框架。静止快照规划不周期发布新Path续命；只在持续安全检查成立时续当前许可。必要时采用单个标准封装消息作为副本入口，确保参考和标识不可错配，对外仍保留几何Path接口。

未来改进：已认证旧参考限时保留、运动中原子换轨、global_monitor调度、端到端执行确认；本基线不实现复杂重规划状态机。

## 6. 参数及实机速度边界

参数文件的分组和注释是明确交付要求，见 [参数约定](parameters.md)。禁止复制原配置后假定所有字段生效。

当前源码配置的target_speed=2.0 m/s、每轴MaxLinear=2.5 m/s不作为本阶段首轮批准速度；setFollowSpeed可能修改目标速度。建议首轮独立合速度硬上限0.20 m/s，**是工程候选，实机放行前确认，不是用户已批准值**。外部速度消息不能突破测试硬上限。

已知需定向核验：MPC加速度代码同时使用上限和正的下限，当前两者均配置5.0；不能据此认定允许0～5 m/s²。末端参考索引取模可能回绕。速度转发每轴±2.4 m/s限幅、0.08 m/s死区、等级比例与底盘真实速度/停车语义需核实。仅修直接影响本次受控移动的项，不改无关模型。

## 7. 分层验收与放行条件

1. **离线**：直线/拐弯/S弯/窄通道/无解；粗细格及负坐标/角点、完整包络距离下界、QP残差/连续性、迭代失败与资源回收；固定输入可复现。
2. **ROS非驱动**：真实话题/QoS、TF/静态地图配准、原点滚动和更新重同步、快照回放、显式请求、无自动重规划、停止/超时及目标抢占。启动无旧发布者竞争，默认执行关闭。
3. **执行链非驱动验证**：参考与许可关联、断联零输出、独立合速度限制、终点边界、转发命令断流保护。不同进程退出路径分别检查，不能只杀规划器测一次。
4. **受控实机移动**：先检查四舵轮执行能力和实物包络；确认允许速度、减速/停稳阈值、超时及可用停车空间。低速直线、绕障/转弯、到达、换目标先停、感知/TF失效和危险先停；危险测试使用隔离/软目标和人工急停，不让人充当障碍。

最终交付须包含实际运行包/二进制与参数、地图/TF、输入和参考记录、实测最大速度、停止响应/距离、跟踪误差及各阶段耗时。离线通过、MPC输出零命令都不能代替实际停车验收。15～20 ms只作后续评估目标，不是未经测量的保证。

用户目前无需再解释整体架构。实施中自行查消息编码/QoS、依赖版本、执行模型及底层消费；首轮速度/实测制动能力等在实机门槛前确认，不阻塞先完成算法和非驱动验证。
