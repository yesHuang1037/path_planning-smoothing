# 第一阶段实现计划：最小改动、逐层验收

日期：2026-10-28。**计划尚未执行；当前只整理文档，不修改源码、启动文件或参数文件。**需求见 [需求与验收](requirements.md)。

## 1. 修改范围与实现组织

- 新建目标为 `transplant_ws/src/tdt_path_planning/`；一个规划核心库、离线入口和ROS薄适配即可，不预建多个微服务或通用插件架构。
- 按需提取本地TDT普通A*、化简、矩形走廊及QP实现；不复制演示主程序、整套导航或未使用后端。复用原ESDF/DynamicVoronoi时限于本次必要接口与所有权修正。
- 执行侧只在新工作区导入必需MPC副本，并记录来源/差异；原速度转发优先复用。若其缺少断流保护且底层无等效保护，再在隔离副本定向补齐，不改串口协议。
- 不动 `transplant_ws_bakup/`、外部导航/SLAM/MPC/TDT，不提交、建分支或刷新固定清单。新工作区创建不恢复旧path_searching；历史脚本路径差异显式记录。

## 2. 工作切片及依赖

### S0 来源核对与最小骨架

**工作**：核对AGENTS、已有改动、源文件身份和许可证；确认ROS/OSQP/OsqpEigen的已安装组合和API，仅缺依赖时解释并请求安装权限。建立新包/测试入口、来源清单及分区参数草稿。核实旧启动链避免重复规划器/MPC。

**验收**：最小包可构建、参数实际加载可打印，离线/ROS默认均不能驱动；不引入无关依赖升级或批量格式化。

### S1 栅格快照、保守距离与A*

**依赖**：S0。

**工作**：统一地图几何、未知/占据语义；接收全量/增量并维护原生costmap，保守面积映射到静态底图。复用距离场并提供经验证的占据面积距离下界，修接入必须的硬编码/双重释放；实现普通A*和端点/边检查。

**测试**：负坐标/格边角、粗细图对齐与不对齐、未知/窗口外、滚动origin、重复覆盖清除；距离下界与小地图暴力面积距离对照；方形包络外接圆/边界、对角穿角、无解、资源析构。最终位置必须连接精确起终点。

**验收**：固定输入得到可复现的有效路线或明确失败；距离不高估真实面积净空，无静态障碍被动态清除。暴力距离只作测试oracle，不默认当生产全图算法。

### S2 化简、QP与检测迭代

**依赖**：S1。

**工作**：接入碰撞感知DP/弦化简、矩形走廊、去重/段时间分配、minimum-jerk QP；补充有限细分与偏差界、插点/收紧、预算、残差及最终发布折线检查。

**测试**：直线/单拐角/S弯/窄通道/走廊不相交、重复点/短段、QP不可行/超时/迭代耗尽，验证端点/C2/速度边界和失败不发布。迭代使用安全参考插点，碰撞容忍固定为零。

**验收**：实际QP后端成功且全链检查通过，或失败保持；不以闭式解/旧样条替代通过。不先追求15～20 ms，记录各阶段和最坏观测耗时。

### S3 两种调试入口与显式请求

**依赖**：S2。

**工作**：离线读取保存快照和参数；ROS接收现有地图、TF、目标，维护一个求解任务及最新请求，目标变化作废旧结果。按同一核心导出初始/化简/优化路径、走廊、状态与输入快照。

**测试**：两入口相同输入的结果/状态一致；地图未就绪的待处理目标、输入无效、目标抢占、更新重同步、求解时地图变化；没有周期/停滞/障碍自动搜索。真实输入可保存回放。

**验收**：非驱动ROS链路接通，默认只发布调试话题，无命令链误激活；无效结果不交付。

### S4 最小执行兼容与停止保护

**依赖**：S3；完成前禁止实机驱动。

**工作**：在MPC副本补充撤销保持、执行本地超时及独立合速度测试上限；定向验证参考/许可编号与失效顺序，不把Bool或旧心跳当新参考许可。优先标准消息；确需封装时只增加单一接缝，不重构全部控制接口。确认停稳再快照规划，持续最新栅格前视检查和有效性续期，危险锁存停止、无自动恢复。

**定向排查**：末端索引取模、加速度下限/梯度及优化失败输出是否直接影响本次执行，先复现再局部修正；不凭字段名默认“约束已生效”。检查速度转发死区、底盘等级与零命令含义，MPC崩溃后下游是否超时停车。必要时只补执行副本的断流保护。

**测试**：旧许可不能解锁新/已撤销Path；乱序、撤销、进程重启、规划器/MPC/转发分别断联；外部速度消息不突破硬上限；停稳超时、新目标先停、到达不回绕、障碍消失不自动恢复。模拟消息可用于非驱动测试，不要求搭建物理仿真。

**验收**：非驱动命令链测试、实际包解析、原节点不竞争，安全检查不被QP阻塞。明确可测的停止响应与感知覆盖要求；无已验证末端断流保护则停在本切片，不宣称可实机放行。

### S5 受控实机移动与交付

**依赖**：S4及现场放行条件。

**放行前**：确认0.60 m包络覆盖真实突出物、base_link中心、四舵轮方向切换能力、静态图物理配准；导出当前参数和运行二进制来源。确认首轮合速度限制（建议0.20 m/s，仍需现场确认）、停稳判据、感知/许可/命令超时和实际制动空间。人员持急停，场地隔离。

**顺序**：非驱动复核→极低速直线/停止验证→短路径到达→受控转弯绕静态软障碍→新目标先停再规划→感知/TF/许可失效停止。先得到基本停车数据再安排障碍介入测试；不让人员作测试障碍，不进行自动绕行/自动恢复验收。

**交付**：离线/ROS/实机结果分开，保存命令、参数、快照/录包、实际最大速度、跟踪误差、停止延迟/距离、各阶段耗时、失败清单。首期完成只表示受控场景可移动，不宣称完整动态闭环导航或急停安全认证。
