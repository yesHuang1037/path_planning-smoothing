# 参数文件分类与注释约定

制定日期：2026-10-28。**本文件是参数交付要求，不是运行时配置。**2026-10-29～30已在新包加入`cfg/planner.yaml`；只声明实际已使用的规划/调试参数，执行保护参数仍未实现。实际加载验证及复现见 [交付记录](delivery.md)。

## 1. 注释原则

- 参数文件按下表分区，区首用简短中文说明用途。单位、有效范围、作用阶段、必要依赖和失败行为有歧义时说明；能从名称直接理解的字段不逐条重复解释。
- 优先保留复用模块的有效参数名，不为注释整齐批量改名；新参数采用一致命名。ROS实际是否支持嵌套分组以代码声明为准，不为美观改变加载接口。
- 区分已确认值、工程初值和实测待定值；计算量/消息元数据不要伪装成可自由调的独立参数。安全关键项缺失或非法时拒绝执行，不能无声回退成零或宽松值。
- 同一安全尺寸只保留一个来源；正文、启动覆盖及运行时打印应一致。每份配置能看清由哪个节点加载，调试/实机启动的覆盖关系必须明确。
- 被复用配置中未生效/兼容保留字段标注一次，不让MaxAngular等名称造成当前实现已有相应硬约束的误解。不要顺便清理无关包全部参数。

## 2. 建议分类

| 分区 | 主要内容 | 需要特别解释的语义 |
| --- | --- | --- |
| A 运行与接口 | 话题、frame、离线/ROS入口、执行开关 | 默认执行关闭；调试输出不进入执行Path |
| B 栅格输入 | 占据阈值、未知策略、全量/增量接收 | 感知未知、窗口外、静态未知分别定义；编码非0～100必须显式适配 |
| C 车体与净空 | body_length/width=0.60 m，margin=0.08 m | 外接圆半径由尺寸计算；中心到占据面积要求约0.504264 m，不独立手填多份 |
| D 搜索与化简 | A*代价、启发权重、DP阈值、搜索预算 | DP阈值不是碰撞容忍；惩罚权重的单位/归一化需说明 |
| E QP与走廊 | 3阶目标/6系数、v_alloc/a_alloc、走廊范围、收缩、最小段时长 | minimum-jerk非snap；分配速度/加速度不等于实车约束 |
| F 检测与预算 | 弦长、偏差界、插点/迭代/采样规模、QP/总时间 | 曲线近似误差如何计入净空；超限失败，不能放宽安全 |
| G 参考输出 | 弧长采样间距、端点容差、调试发布 | 空Path为撤销；时间采样dt不是MPC执行周期 |
| H 状态与保护 | TF/感知有效期、前视范围、监控节拍、停稳条件、许可时限 | 不等同重规划节流；安全保护独立于求解；静态TF时间戳单独处理 |
| I 执行副本 | 测试合速度上限、目标速度、到达/减速、必要加速度约束 | 目标速度不能绕过测试硬上限；停车距离实测；原下限5.0语义需先核验 |

## 3. 初值登记与边界

| 项目 | 当前状态 |
| --- | --- |
| 车体0.60×0.60 m、中心base_link、余量0.08 m | 用户确认；包络半径0.424264 m，面积距离净空阈值0.504264 m，由尺寸派生 |
| 静态图约0.05 m/格、costmap约0.10 m/格 | 上游配置事实；实际读取消息，不配置成独立强制搜索分辨率 |
| costmap阈值65 | 沿用候选；结合真实编码验证 |
| DP偏差0.10 m、输出间距0.10 m、最大细化轮数6 | 工程初值；新版本测试后调整，不借用T02-A历史结果作证 |
| minimum-jerk/五次/OSQP走廊 | 本基线单一后端；首期可固定，不要求暴露无用切换参数 |
| 首轮合速度上限0.20 m/s | 建议候选；未视作用户已批准实机值，放行前确认 |
| 前视距离、监控节拍、超时、停稳阈值、a_alloc | 结合死区、实际延迟和停车能力设定；可离线配置测试值，但无依据不得实机放行 |
| 0.50 s/1.5 s及停滞窗口 | 原global_monitor历史参数，本基线不启用自动重规划，不照搬进有效配置制造误导 |

本轮已落盘的离线/调试工程值：`allocation_speed=0.20 m/s`、`allocation_acceleration=0.20 m/s²`只用于时间分配；输入有效期`max_input_age_s=0.5 s`、起点漂移`max_start_drift_m=0.05 m`只用于调试候选筛选。均不等于已批准的实机速度、执行超时或安全停车阈值。配置只支持重启生效，在线更改明确拒绝。`simplify_epsilon`仅约束DP步骤，后续安全弦合并不承诺保留同一几何偏差上限；最终碰撞判据仍不放宽。

参数交付检查：分类可读、单位不混、派生值不重复、非法值有测试、加载来源可追溯、实际生效值可导出；避免堆砌逐字翻译式注释。
