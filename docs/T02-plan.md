## 行为与异常

新模式保留端点/点序，先 DP 再弦化简，仅接受覆盖栅格均满足原占据和净空判据的新连线。不可证明安全时保留原点，不扩大起点脱困豁免，也不声称保留路径整体安全。弦阶段不承诺 DP 偏离阈值仍为全局上限。

拒绝未知模式、负/非有限阈值、非有限/不可索引坐标和无效环境；空输入单独报错，单点/双点与重复点有定义处理。非法输入不能被当成普通空平滑结果回退；只调整进程内错误传递，不新增 ROS 消息。地图变更沿用当前同步回调，每次读取当前合成环境。
